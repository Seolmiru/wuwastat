## 패치 노트 v0.4.0

### 1. 추천 파티 추가
- 캐릭터마다 공식 공략 사이트의 추천 파티를 초상화와 함께 보여줍니다.
  - 예) 에이메스 - 린네 - 모니에 / 에이메스 - 데니아 - 모니에 / 에이메스 - 루파 - 모니에
- 모드를 고르는 캐릭터는 함께 쓰는 캐릭터에 맞는 모드를 초상화 아래에 표시합니다.
  - 예) 에이메스 파티의 린네 **밀집**, 데니아 **불꽃** / 히유키 파티의 루실라 **서리**

### 2. UI 개선
- 화면 전체를 어두운 테마로 통일하고, 구역마다 카드와 강조색 제목을 넣어 한눈에 구분되게 했습니다.
- 등급을 색깔 배지로, 종합 점수를 큰 숫자로 표시합니다.
- 캐릭터 이름을 속성 색으로 표시하고 속성 배지를 추가했습니다.
- 목표 스탯이 달성되면 초록, 모자라면 주황으로 표시합니다.
- 안내 문구를 더 밝게 바꿔 읽기 쉽게 했습니다.
- 글자를 키워도 왼쪽 캐릭터 정보가 잘리지 않습니다.
- 육성 가이드를 장착 에코처럼 접고 펼 수 있습니다.
