# wuwastat

명조(Wuthering Waves) 캐릭터 육성 등급 계산기 (Windows 데스크톱 앱, PySide6)

캐릭터 스탯 화면과 에코 화면 스크린샷을 읽어서 다음을 보여줍니다.

- **종합 등급** (SSS ~ D)
- 공식 공략의 **추천 스탯 대비 달성도**와 부족한 수치 (서브옵션 몇 줄이 더 필요한지)
- **에코별 점수**와 **교체 우선순위**: 가장 먼저 바꿔야 할 에코, 바꾸면 오르는 점수

## 설치 (권장: 포터블 ZIP)

지인용 자세한 안내: [docs/INSTALL.md](docs/INSTALL.md) · 배포 절차: [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md)

Python이나 Git을 설치할 필요가 없습니다.

1. [Releases](../../releases) 페이지에서 `wuwastat-<버전>-win64.zip`을 내려받습니다.
2. **ZIP 파일 우클릭 > 속성 > 아래쪽 '차단 해제' 체크 > 확인** (인터넷에서 받은 파일 경고를 없앱니다)
3. 짧은 경로에 압축을 풉니다 (예: `C:\wuwastat`).
4. `wuwastat.bat`을 더블클릭합니다.

- 필요 조건: Windows 10/11 64비트, Windows 한국어 OCR 언어팩 (아래 참고)
- 실행되는 프로그램은 ZIP 안의 `python\pythonw.exe`이며 Python 재단이 서명한 공식 파일입니다.
  이 프로젝트가 만든 실행 파일(.exe)은 없어서 코드 서명 없이도 배포할 수 있습니다.
- 업데이트: 새 버전 ZIP을 새 폴더에 풀어 쓰면 됩니다. 입력값은 `%APPDATA%\wuwastat\wuwastat\builds`에 그대로 남습니다.

## 실행 (소스에서, 개발자용)

Git으로 받은 경우 `run.bat`을 더블클릭하세요. 처음 실행할 때 가상환경을 만들고 패키지를 설치합니다 (Python 3.11 이상 필요).

직접 실행하려면:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m wuwastat
```

**필요 조건**
- Windows 10/11
- Python 3.11 이상
- 프로젝트 폴더는 짧은 경로에 두세요 (예: `C:\wuwastat`). 경로가 길면 Windows 경로 길이 제한(260자) 때문에
  PySide6 설치가 실패할 수 있습니다.
- Windows 한국어 OCR 언어팩 (한국어 Windows에는 보통 기본으로 설치돼 있습니다.
  없으면 설정 > 시간 및 언어 > 언어 > 한국어 > 언어 옵션에서 설치)

## 사용법

1. 위쪽에서 캐릭터를 고릅니다 (이름 일부만 입력해도 검색됩니다).
2. **캐릭터 총 스탯**: 게임의 캐릭터 속성 상세 화면 스크린샷을 `스크린샷 열기`로 열거나, 끌어다 놓거나, 복사한 뒤 `Ctrl+V`로 붙여넣습니다.
3. **장착 에코**: 에코 상세 화면 스크린샷을 탭마다 하나씩 넣거나, `에코 스크린샷 여러 장 열기`로 최대 5장을 한 번에 넣습니다.
4. OCR이 잘못 읽은 값은 표에서 바로 고칠 수 있습니다. 값을 고치면 결과가 자동으로 다시 계산됩니다.
5. 입력한 값은 캐릭터별로 자동 저장됩니다 (`%APPDATA%\wuwastat\wuwastat\builds`).

## 세팅 자동 측정

스크린샷을 따로 찍지 않고, 게임 화면을 보면서 자동으로 채우는 방법입니다.

1. 명조를 **창 모드나 테두리 없는 창 모드**로 실행합니다. (독점 전체 화면은 캡처가 검게 나올 수 있습니다)
2. 앱에서 `세팅 자동 측정 시작`을 누릅니다.
3. 게임에서 캐릭터의 **속성 상세정보** 화면을 엽니다. 캐릭터 이름을 알아보고 총 스탯을 읽습니다.
   - 방랑자는 이름 대신 속성으로 구분합니다.
4. **에코 화면**으로 넘어가 에코 5개를 하나씩 클릭합니다. 새 에코가 보일 때마다 1~5번 칸에 채웁니다.
   같은 에코를 다시 열어도 두 번 세지 않습니다.
5. 에코 5개를 모두 읽으면 측정이 끝납니다. `자동 측정 중지`로 언제든 멈출 수 있습니다.

- 화면 종류는 작은 영역만 읽어 판별합니다 (왼쪽 위 '속성 상세정보' 제목, 오른쪽 위 에코 상세 패널). 0.2초마다 확인합니다.
- 화면 전환이 끝나 글자 영역이 멈췄을 때 한 번만 읽습니다. 캐릭터 화면은 약 1초, 에코 하나는 약 1초 걸립니다.
- 총 스탯은 6개(HP·공격력·방어력·공명 효율·크리티컬·크리티컬 피해)가 그럴듯한 범위로 모두 읽혔을 때만 반영하고,
  덜 읽히면 다시 읽습니다. 같은 화면을 다시 읽어도 결과는 한 번만 반영합니다.

- 게임에 대해 하는 일은 두 가지뿐입니다. 테스트(`test_gamewatch_never_touches_game_process_or_input`)로 고정되어 있습니다.
  - 창 정보 조회: 창 목록·제목·창 클래스·위치·맨 앞 창인지 (Windows 창 관리자 정보)
  - 화면 픽셀 읽기: 게임 창이 맨 앞에 있을 때 그 영역의 데스크톱 화면을 캡처 (화면 녹화 프로그램과 같은 방식)
- 하지 않는 것: 클릭·키 입력 전송, 게임 프로세스 열기(핸들), 메모리 읽기·쓰기, DLL 주입, 후킹, 게임 파일 접근, 통신.
- 캡처한 화면은 메모리에서만 쓰고 **파일로 저장하지 않습니다.**
- 명조 이용약관은 회사가 승인하지 않은 제3자 프로그램 사용을 금지하고, 공정 플레이 정책은 매크로를 금지합니다.
  이 기능은 입력을 보내지 않도록 만들었지만, 쿠로게임즈가 이런 도구를 허용한다고 밝힌 적은 없습니다.
  사용은 본인 판단과 책임으로 하세요.

## 초상화

- 캐릭터 정보 위에 캐릭터 초상화, 에코 탭과 결과 표에 에코 초상화를 보여줍니다.
- 이미지는 저장소의 `assets` 폴더에 들어 있고, 앱은 이 파일만 읽습니다. **앱이 이미지를 받으려고 사이트에 접속하지 않습니다.**
  - `assets/portraits/<캐릭터 ID>.png`, `assets/echoes/*.png` + `assets/echoes/index.json` (에코 이름 → 파일)
  - 출처: 명조 공식 공략 사이트의 이미지 (쿠로게임즈 저작물)
- 에코 초상화는 공식 공략에 추천으로 나오는 에코(현재 45종, 대부분 4코스트 메인 에코)만 있습니다.
  이미지가 없는 에코는 코스트만 표시합니다. OCR로 읽은 에코 이름이 한두 글자 틀려도 비슷한 이름으로 찾습니다.
- 이미지를 새로 받을 때(개발자): `python -m wuwastat.scraper --export-slim --download-images`
  (공식 CDN의 https 주소만 받고, 5MB 이하의 실제 이미지인지 확인한 뒤 160px PNG로 저장)

## 아이콘

갈브레나 초상화를 32×32 도트 그림으로 바꾼 아이콘입니다 (`assets/icon.ico`, `assets/icon.png`).
다시 만들려면 `python tools/make_icon.py`를 실행하세요.

## 캐릭터 데이터

[명조 공식 공략 사이트](https://wuwaguide.kurogames.com/ko/)에서 캐릭터마다 추천 수가 가장 많은 한국어 공략을 가져옵니다.

| 파일 | 내용 | 저장소 |
|---|---|---|
| `data/characters.json` | 계산에 필요한 숫자와 이름만: 추천 스탯 수치, 코스트별 추천 메인옵션, 서브옵션 우선순위, 메인 에코·세트·무기·공명 체인 이름 | 포함 |
| `data/characters.local.json` | 앱에서 `캐릭터 데이터 업데이트`를 누르면 받는 전체 데이터 (공략 설명 글, 무기·공명 체인 효과 문구 포함) | 제외 (.gitignore) |

앱은 `characters.local.json`이 있으면 그것을 씁니다. 공명 체인 효과 문구가 필요한 **돌파 효율 계산은 업데이트를 한 번 한 뒤에**
동작합니다. 공략 설명 글은 작성자와 쿠로게임즈의 저작물이므로 저장소에는 올리지 않습니다.

명령으로 업데이트하려면:

```
.venv\Scripts\python -m wuwastat.scraper                 # 전체 데이터 → data/characters.local.json
.venv\Scripts\python -m wuwastat.scraper --export-slim   # 저장소용 data/characters.json 도 함께 갱신
```

## 점수 계산

### 에코 등급 (희귀도 기준)
서브옵션 확률은 [쿠로게임즈 한국 확률 공시](https://wutheringwaves.kurogames.com/p/language_ko/product_info.html)를 따릅니다.
서브옵션 13종은 각각 7.69%로 같은 확률로 나오고 한 에코 안에서 중복되지 않습니다. 수치는 종류마다 확률이 다릅니다
(예: 크리티컬 10.5%는 3%, 6.3~7.5%는 각 23.3%).

1. 서브옵션 가치 = Σ `값 / 최대 롤 값 × 우선순위 가중치` (우선순위 1~6등급에 1.0 / 0.8 / 0.6 / 0.45 / 0.35 / 0.3,
   고정 수치 옵션은 같은 계열 %옵션의 절반). 메인옵션이 추천과 다르면 ×0.6.
2. 공식 확률로 '새 에코를 끝까지 강화했을 때 나올 수 있는 모든 에코'의 가치 분포를 정확히 계산하고,
   내 에코가 그중 몇 %보다 좋은지(백분위)를 에코 점수로 씁니다.
3. 에코 등급: SSS 상위 1%, SS 상위 3%, S 상위 8%, A 상위 20%, B 상위 40%, C 상위 65%, 그 아래 D

### 종합 등급
| 항목 | 계산 |
|---|---|
| 목표 달성도 | 100 - (부족한 수치를 서브옵션 줄 수로 환산 × 12). 1줄 = 공식 확률로 계산한 기대값 (크리티컬 7.53%, 크리티컬 피해 15.06%, 공명 효율 9.36% 등) |
| 에코 항목 | 에코 평균 백분위 50(아무 에코 수준) → 0점, 95(모두 상위 5%) → 100점 |
| 종합 점수 | 목표 달성도 50% + 에코 항목 50% |
| 종합 등급 | SSS ≥ 95, SS ≥ 88, S ≥ 80, A ≥ 70, B ≥ 60, C ≥ 45, 그 아래 D. **추천 스탯을 하나라도 못 채우면 최대 A** |

### 육성 가이드
- 부족한 스탯은 서브옵션 몇 줄이 필요한지로 안내합니다. 메인옵션 변경은 공략이 그 코스트에 추천하는 옵션일 때만 제안합니다.
- 교체할 에코는 메인옵션 불일치 → 희귀도 낮은 순으로 고릅니다. 그 에코를 빼면 잃는 서브옵션까지 계산해서
  새 에코가 채워야 할 수치를 알려줍니다.
- 무기·에코 세트는 공식 공략의 추천 목록(전용 무기 포함) 기준으로만 안내합니다. 에코 세트는 3세트 + 2세트처럼
  두 세트 조합을 고를 수 있습니다.
- 돌파: 공식 공략이 꼽은 핵심 돌파와 다음에 노릴 돌파를 안내합니다.

### 돌파 효율 (추정)
공식 공명 체인 효과 문구의 수치를 읽어, 돌파할 때마다 DPS가 몇 % 늘어나는지 추정합니다 (`wuwastat/chain.py`).
버프를 스탯에 더하지 않고, 현재 스탯을 넣은 데미지 공식에서 효과가 있을 때와 없을 때의 비율만 계산합니다.

- 피해 배율 X% 상승 → 그 스킬의 딜 비중 × X% (딜 비중은 공략 서브옵션 우선순위의 주력 스킬을 키워서 어림)
- 크리티컬/크리티컬 피해 증가 → 크리티컬 기대값 `1 + 크리티컬 × (크리티컬 피해 - 1)`의 증가율
- 공격력 X% → X% × 기본 공격력 / 총 공격력, 피해 보너스 X% → X / (100 + 기존 피해 보너스 80)
- 피해 부스트, 저항 감소, 방어력 무시도 각각의 곱 항으로 계산
- "~발동 시," 앞부분은 조건이므로 적용 범위에서 뺍니다. "최대 N%"는 최대치, 버프 유지율은 100%로 봅니다.
- 문구로 크기를 알 수 없는 효과는 핵심 돌파 8%, 일반 돌파 2%로 두고 화면에 `*`로 표시합니다.

돌파 반영 점수 = 종합 점수 + (0돌 대비 DPS 증가율을 우선순위 1순위 서브옵션 몇 줄 분량인지로 환산 × 6점).
추천 스탯을 못 채우면 돌파 반영 등급도 최대 A입니다.

## 개발

```
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest tests
```

패키지 버전은 `requirements.txt`에 검증한 버전으로 고정되어 있습니다. 올릴 때는 테스트를 통과하는지 확인한 뒤 바꾸세요.

## 배포 (새 버전 내기)

1. `wuwastat/__init__.py`의 `__version__`을 올리고 커밋합니다 (예: `0.2.0`).
2. 같은 이름의 태그를 만들어 올립니다.
   ```
   git tag v0.2.0
   git push origin v0.2.0
   ```
3. GitHub Actions(`.github/workflows/release.yml`)가 테스트 → 포터블 ZIP 빌드 → Releases 업로드를 자동으로 합니다.
   지인에게는 Releases 페이지 링크만 보내면 됩니다.

직접 만들려면 `python tools/build_portable.py` → `build/wuwastat-<버전>-win64.zip`.
빌드는 python.org의 공식 임베디드 Python을 받아 Python 재단 서명을 확인한 뒤, 고정된 버전의 패키지를 넣고
쓰지 않는 Qt 구성요소(QML, 디자이너 도구 등)를 지웁니다.

## 개인정보와 보안

- 스크린샷은 PC 안에서만 처리합니다 (Windows 내장 OCR). 외부로 전송하지 않습니다.
- 인터넷 통신은 `캐릭터 데이터 업데이트`를 누를 때 공식 공략 서버(`guide-server.aki-game.net`)에 HTTPS로
  요청하는 것뿐입니다. 응답은 10MB로 제한하고, 캐릭터 ID는 숫자만 받습니다. 초상화는 저장소 파일을 쓰므로 접속하지 않습니다.
- 입력값은 `%APPDATA%\wuwastat\wuwastat\builds`에 캐릭터별 JSON으로 저장합니다. 파일이 손상되면 무시하고 새로 시작합니다.
- 캐릭터 정보의 링크는 공식 공략 사이트(https)만 엽니다.
