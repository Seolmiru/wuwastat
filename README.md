# wuwastat

명조(Wuthering Waves) 캐릭터 육성 등급 계산기 (Windows 데스크톱 앱, PySide6)

캐릭터 스탯 화면과 에코 화면 스크린샷을 읽어서 다음을 보여줍니다.

- **종합 등급** (SSS ~ D)
- 공식 공략의 **추천 스탯 대비 달성도**와 부족한 수치 (서브옵션 몇 줄이 더 필요한지)
- **에코별 점수**와 **교체 우선순위**: 가장 먼저 바꿔야 할 에코, 바꾸면 오르는 점수

## 실행

`run.bat`을 더블클릭하세요. 처음 실행할 때 가상환경을 만들고 패키지를 설치합니다.

직접 실행하려면:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m wuwastat
```

**필요 조건**
- Windows 10/11
- Python 3.11 이상
- Windows 한국어 OCR 언어팩 (한국어 Windows에는 보통 기본으로 설치돼 있습니다.
  없으면 설정 > 시간 및 언어 > 언어 > 한국어 > 언어 옵션에서 설치)

## 사용법

1. 위쪽에서 캐릭터를 고릅니다 (이름 일부만 입력해도 검색됩니다).
2. **캐릭터 총 스탯**: 게임의 캐릭터 속성 상세 화면 스크린샷을 `스크린샷 열기`로 열거나, 끌어다 놓거나, 복사한 뒤 `Ctrl+V`로 붙여넣습니다.
3. **장착 에코**: 에코 상세 화면 스크린샷을 탭마다 하나씩 넣거나, `에코 스크린샷 여러 장 열기`로 최대 5장을 한 번에 넣습니다.
4. OCR이 잘못 읽은 값은 표에서 바로 고칠 수 있습니다. 값을 고치면 결과가 자동으로 다시 계산됩니다.
5. 입력한 값은 캐릭터별로 자동 저장됩니다 (`%APPDATA%\wuwastat\builds`).

## 캐릭터 데이터

`data/characters.json`에는 [명조 공식 공략 사이트](https://wuwaguide.kurogames.com/ko/)에서 가져온 캐릭터별 정보가 들어 있습니다.

- 추천 스탯 (예: 크리티컬 ≥ 70%, 크리티컬 피해 ≥ 240%, 공명 효율 ≥ 120%)
- 코스트별 추천 에코 메인옵션, 메인 에코, 세트
- 서브옵션 우선순위 (예: `크확/크피>공격력 백분율>강공격 피해 보너스>공명 효율`)

캐릭터마다 추천 수가 가장 많은 한국어 공략을 씁니다. 새 캐릭터가 나오면 앱의
`캐릭터 데이터 업데이트` 버튼을 누르거나 아래 명령을 실행하세요.

```
.venv\Scripts\python -m wuwastat.scraper
```

## 점수 계산

### 에코 등급 (희귀도 기준)
서브옵션 확률은 [쿠로게임즈 한국 확률 공시](https://wutheringwaves.kurogames.com/p/language_ko/product_info.html)를 따릅니다.
서브옵션 13종은 각각 7.69%로 같은 확률로 나오고 한 에코 안에서 중복되지 않습니다. 수치는 종류마다 확률이 다릅니다
(예: 크리티컬 10.5%는 3%, 6.3~7.5%는 각 23.3%).

1. 서브옵션 가치 = Σ `값 / 최대 롤 값 × 우선순위 가중치` (우선순위 1~6등급에 1.0 / 0.8 / 0.6 / 0.45 / 0.35 / 0.3,
   고정 수치 옵션은 같은 계열 %옵션의 절반). 메인옵션이 추천과 다르면 ×0.6.
2. 공식 확률로 '새 에코를 끝까지 강화했을 때 나올 수 있는 모든 에코'의 가치 분포를 정확히 계산하고,
   내 에코가 그중 몇 %보다 좋은지(백분위)를 에코 점수로 씁니다.
3. 에코 등급: SSS 상위 1%, SS 상위 3%, S 상위 8%, A 상위 20%, B 상위 40%, C 상위 65%, 그 아래 D

### 종합 등급
| 항목 | 계산 |
|---|---|
| 목표 달성도 | 100 - (부족한 수치를 서브옵션 줄 수로 환산 × 12). 1줄 = 공식 확률로 계산한 기대값 (크리티컬 7.53%, 크리티컬 피해 15.06%, 공명 효율 9.36% 등) |
| 에코 항목 | 에코 평균 백분위 50(아무 에코 수준) → 0점, 95(모두 상위 5%) → 100점 |
| 종합 점수 | 목표 달성도 50% + 에코 항목 50% |
| 종합 등급 | SSS ≥ 95, SS ≥ 88, S ≥ 80, A ≥ 70, B ≥ 60, C ≥ 45, 그 아래 D. **추천 스탯을 하나라도 못 채우면 최대 A** |

### 육성 가이드
- 부족한 스탯은 서브옵션 몇 줄이 필요한지로 안내합니다. 메인옵션 변경은 공략이 그 코스트에 추천하는 옵션일 때만 제안합니다.
- 교체할 에코는 메인옵션 불일치 → 희귀도 낮은 순으로 고릅니다. 그 에코를 빼면 잃는 서브옵션까지 계산해서
  새 에코가 채워야 할 수치를 알려줍니다.
- 무기·에코 세트는 공식 공략의 추천 목록(전용 무기 포함) 기준으로만 안내합니다. 에코 세트는 3세트 + 2세트처럼
  두 세트 조합을 고를 수 있습니다.
- 돌파: 공식 공략이 꼽은 핵심 돌파와 다음에 노릴 돌파를 안내합니다.

### 돌파 효율 (추정)
공식 공명 체인 효과 문구의 수치를 읽어, 돌파할 때마다 DPS가 몇 % 늘어나는지 추정합니다 (`wuwastat/chain.py`).
버프를 스탯에 더하지 않고, 현재 스탯을 넣은 데미지 공식에서 효과가 있을 때와 없을 때의 비율만 계산합니다.

- 피해 배율 X% 상승 → 그 스킬의 딜 비중 × X% (딜 비중은 공략 서브옵션 우선순위의 주력 스킬을 키워서 어림)
- 크리티컬/크리티컬 피해 증가 → 크리티컬 기대값 `1 + 크리티컬 × (크리티컬 피해 - 1)`의 증가율
- 공격력 X% → X% × 기본 공격력 / 총 공격력, 피해 보너스 X% → X / (100 + 기존 피해 보너스 80)
- 피해 부스트, 저항 감소, 방어력 무시도 각각의 곱 항으로 계산
- "~발동 시," 앞부분은 조건이므로 적용 범위에서 뺍니다. "최대 N%"는 최대치, 버프 유지율은 100%로 봅니다.
- 문구로 크기를 알 수 없는 효과는 핵심 돌파 8%, 일반 돌파 2%로 두고 화면에 `*`로 표시합니다.

돌파 반영 점수 = 종합 점수 + (0돌 대비 DPS 증가율을 우선순위 1순위 서브옵션 몇 줄 분량인지로 환산 × 6점).
추천 스탯을 못 채우면 돌파 반영 등급도 최대 A입니다.

## 구조

```
wuwastat/
  scraper.py   공식 공략 사이트 API 수집 → data/characters.json
  stats.py     스탯 키, 한국어 이름 매핑, 에코 옵션 수치표
  models.py    데이터 모델
  ocr.py       Windows 내장 OCR 호출과 이미지 전처리
  parser.py    OCR 결과 → 총 스탯 / 에코 해석 (여러 전처리 결과를 줄 단위로 합침)
  scoring.py   등급 계산, 교체 우선순위, 육성 가이드
  chain.py     공명 체인(돌파) DPS 상승률 추정
  ui.py        PySide6 화면
tests/         단위 테스트 (python -m pytest tests)
```
